# Pareto de Falhas QG09 - V0.9

Versão V0.9 com mudança no Pareto principal.

## Novidades

- O Pareto principal agora agrupa por falha geral (`D1_GERAL`).
- Exemplo: `PEÇA ACABAMENTO FORA DO ESPECIFICADO`, `CORDÃO INCOMPLETO`, `RESPINGOS`.
- Nova aba `Estratificar TOP`.
- Ao escolher um TOP, o app mostra a distribuição por modelo.
- Ao escolher um modelo, o app mostra as falhas completas daquele TOP/modelo.
- Mantém calendário acumulativo, QG09 fixo e modos Diário/Semanal/Mensal/YTD/Personalizado.

## Deploy no Streamlit Cloud

Use como **Main file path**:

```text
app_V0_9.py
```

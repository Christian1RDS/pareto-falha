# Pareto QG09 - V0.12

Versão V0.12 adiciona um **gráfico Top 10** embaixo do ranking das falhas completas.

## Ajuste

Na aba **Estratificar TOP**, depois de escolher:

- o TOP desejado;
- `Todos` ou um modelo específico;

O app mostra:

1. A tabela **Ranking das falhas completas**;
2. Um gráfico logo abaixo com o **Top 10 das falhas completas**, por quantidade.

## Deploy

Use como Main file path:

```text
app_V0_12.py
```

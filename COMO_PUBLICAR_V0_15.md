# Como publicar V0.15

Suba:

```text
app_V0_15.py
requirements.txt
README_V0_15.md
.gitignore
.streamlit/config.toml
```

Main file path:

```text
app_V0_15.py
```

Logo oficial:

```text
agco_logo.png
```

Baixe o PNG oficial na Media Gallery da AGCO e coloque esse arquivo na raiz do repositório.

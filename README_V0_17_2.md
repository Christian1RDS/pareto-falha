# Pareto QG09 - V0.17.2

Versão V0.17 adiciona cinco novas análises ao site:

1. **Estratificação por região da cabine/estrutura**
2. **Matriz Modelo x Falha**
3. **Tendência semanal por falha escolhida**
4. **Antes x Depois de uma ação**
5. **Classificação automática de defeitos de solda**

Também mantém:

- Pareto clássico com linha de 80%;
- carregamento flexível do logo AGCO;
- upload acumulativo;
- filtros por ano, período, modelo, origem e área.

## Deploy

Use como Main file path:

```text
app_V0_17.py
```


### Ajustes aplicados na V0.17.2

Esta versão preserva a V0.17 original e aplica somente dois ajustes:

1. Adiciona a opção **Todos** na aba **Pareto por Modelo**.
2. Adiciona um **Pareto clássico Modelo / Falha** abaixo da matriz na aba **Matriz Modelo x Falha**.

Não foram adicionados índice de criticidade, controle de estabilidade, alertas, foco da semana ou abas novas.

### Deploy

Use como Main file path:

```text
app_V0_17_2.py
```

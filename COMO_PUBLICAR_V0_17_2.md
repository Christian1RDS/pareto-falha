# Como publicar V0.17.2

Suba:

```text
app_V0_17_2.py
requirements.txt
README_V0_17_2.md
.gitignore
.streamlit/config.toml
```

No Streamlit Cloud, use como **Main file path**:

```text
app_V0_17_2.py
```

Esta versão preserva a V0.17 original e aplica somente:

1. opção **Todos** na aba Pareto por Modelo;
2. Pareto clássico **Modelo / Falha** na aba Matriz Modelo x Falha.

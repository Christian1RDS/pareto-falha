# Como publicar a versão V0.6

Suba estes arquivos no GitHub:

```text
app_V0_6.py
requirements.txt
README_V0_6.md
.gitignore
.streamlit/config.toml
COMO_PUBLICAR_V0_6.md
```

No Streamlit Cloud, use como **Main file path**:

```text
app_V0_6.py
```

A V0.6 corrige a leitura de cabeçalhos com variações como `CD\_POSTO\_CN` e `DT HR INSPECAO`.

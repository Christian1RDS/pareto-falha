# Pareto QG09 - V0.10

Versão V0.10 com a opção **Todos** na etapa:

```text
Escolha o modelo para ver as informações completas
```

## O que muda

- Ao escolher `Todos`, o app mostra o ranking geral das falhas completas daquele TOP específico.
- O ranking vem ordenado por quantidade.
- Exemplo:

```text
1 - GLAZED FRAME G7 TRASEIRA PONTO 359 SOLDA - RESPINGOS (qtd-500)
2 - GLAZED FRAME G8 FECHAMENTO SUPERIOR PONTO 1 SOLDA - RESPINGOS (qtd-350)
3 - GLAZED FRAME G8 FECHAMENTO SUPERIOR PONTO 2 SOLDA - RESPINGOS (qtd-200)
```

## Deploy

Use como Main file path:

```text
app_V0_10.py
```

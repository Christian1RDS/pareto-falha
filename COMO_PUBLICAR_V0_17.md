# Como publicar V0.17

Suba:

```text
app_V0_17.py
requirements.txt
README_V0_17.md
.gitignore
.streamlit/config.toml
```

No Streamlit Cloud, use como **Main file path**:

```text
app_V0_17.py
```

Se quiser logo no cabeçalho, coloque o logo AGCO na raiz do repositório com um dos nomes aceitos no README da V0.16/V0.17.

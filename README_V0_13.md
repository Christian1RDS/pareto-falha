# Pareto QG09 - V0.13

Versão V0.13 corrige a ordenação do gráfico Top 10 e atualiza o visual para um estilo mais corporativo inspirado na AGCO.

## Ajustes

- O **Gráfico Top 10 - falhas completas** usa o mesmo ranking da tabela e mantém a ordem decrescente por quantidade.
- O gráfico deixou de usar `st.bar_chart` nessa parte e passou a usar SVG interno para preservar a ordem visual.
- O layout usa uma paleta corporativa inspirada em AGCO: vermelho, preto, branco e cinza.

## Deploy

Use como Main file path:

```text
app_V0_13.py
```

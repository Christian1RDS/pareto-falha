# Pareto de Falhas QG09 - V0.8

Versão V0.8 com calendário acumulativo e modos de período.

## Novidades

- Considera somente registros QG09.
- Permite somar 2025 e 2026 no mesmo calendário.
- Modos: Diário, Semanal, Mensal, Anual YTD e Personalizado.
- O modo Personalizado mantém seleção manual de período.
- Continua sem Plotly.

## Deploy no Streamlit Cloud

Use como **Main file path**:

```text
app_V0_8.py
```

# Pareto QG09 - V0.15

Versão V0.15 com Pareto clássico e cabeçalho preparado para o logo oficial da AGCO.

## Ajustes

- Gráficos voltaram ao padrão de Pareto clássico:
  - barras ordenadas por quantidade;
  - linha de percentual acumulado;
  - linha pontilhada de 80%;
  - legenda de Quantidade, % acumulado e Meta 80%.
- Visual escuro corporativo inspirado no site da AGCO.
- Logo oficial: baixe o PNG oficial na Media Gallery da AGCO e salve no repositório como `agco_logo.png`.
- Se `agco_logo.png` existir, o app carrega automaticamente no cabeçalho.

## Deploy

Use como Main file path:

```text
app_V0_15.py
```

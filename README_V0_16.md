# Pareto QG09 - V0.16

Versão V0.16 com carregamento flexível do logo AGCO e Pareto clássico com linha de 80%.

## Logo AGCO

O app procura automaticamente estes nomes na raiz do repositório:

```text
agco_logo.png
AGCO_logo.png
agco-logo.png
logo_agco.png
logo.png
AGCO.png
agco.png
agco_corporate_logo.png
AGCO_Corporate_Logo.png
```

Se encontrar qualquer um deles, o logo aparece no cabeçalho. Se nenhum aparecer, o app usa o fallback textual `AGCO Corporation`.

## Deploy

Use como Main file path:

```text
app_V0_16.py
```
